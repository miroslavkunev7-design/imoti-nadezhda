ИНСТАЛАЦИЯ НА INFINITYFREE МОСТ (5 мин)
=====================================

1. Влез в InfinityFree → File Manager → htdocs

2. Създай папка: db-bridge

3. Качи файловете от папката infinityfree-bridge/:
   - api.php
   - upload.php
   - .htaccess

4. Копирай config.example.php → config.php

5. Отвори config.php и попълни:
   - db_host, db_name, db_user, db_pass  (от phpMyAdmin)
   - api_key  (измисли дълъг секрет, напр. 32+ символа)
   - public_url  (https://твоят-сайт.infinityfreeapp.com)

6. Създай папка htdocs/uploads/properties/ (празна)

7. Тествай в браузъра (POST с Postman) или след Vercel deploy.


VERCEL DEPLOY
=============

A) През сайта (най-лесно, без Git):
   1. https://vercel.com → New Project
   2. Import → качи ZIP на проекта или свърни GitHub
   3. Framework: Next.js (автоматично)
   4. Environment Variables (Production):

      DB_BRIDGE_URL = https://ТВОЯТ-САЙТ.infinityfreeapp.com/db-bridge/api.php
      DB_BRIDGE_KEY = (същият api_key от config.php)
      NEXT_PUBLIC_MEDIA_URL = https://ТВОЯТ-САЙТ.infinityfreeapp.com
      NEXT_PUBLIC_SITE_URL = https://твоят-проект.vercel.app
      ADMIN_EMAIL = (твоят admin имейл)
      ADMIN_PASSWORD = (твоя admin парола)
      NEXTAUTH_SECRET = (дълъг случаен стринг)
      NEXT_PUBLIC_SITE_NAME = Имоти Надежда
      NEXT_PUBLIC_CONTACT_PHONE = +359899620262
      NEXT_PUBLIC_CONTACT_EMAIL = agenciq_nadejdi@abv.bg

   5. Deploy

B) От компютъра:
   Двоен клик на deploy-vercel.bat
   (или: npx vercel deploy --prod)


След deploy
===========
- Admin: 3 клика на логото → login
- Добави имот → записва се в InfinityFree базата
- Снимки → качват се на InfinityFree (upload.php)
